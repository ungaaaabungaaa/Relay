# Relay support

Contact `support@relayforcodex.com` for Relay Mac or Apple Watch App Store build
setup, pairing, accessibility, revocation, Emergency Stop, or account deletion.
The owner must operate the mailbox and response process before submitting the
App Store build.

Do not send credentials, sign-in links, pairing codes, fingerprints, prompts,
commands, repository paths, task output, or audio in a support request. Export
the redacted diagnostic package from Relay for Mac.

For connection problems, keep the Mac awake, confirm Relay Cloud is connected,
and refresh the Apple Watch app. An offline Apple Watch blocks mutations.
Revoke a lost Apple Watch from Relay for Mac. Use Emergency Stop before
contacting support if you suspect account or device compromise.

Report vulnerabilities through GitHub private vulnerability reporting when the
project enables it. Give the owner time to investigate before publishing
security details.

Delete an account from **Relay for Mac > Relay Cloud > Delete Relay Account**.
If the Mac is unavailable, email support from the invited address. Do not send
a refresh token or device credential. Deletion removes cloud account and
device metadata and leaves local Codex tasks and repositories in place.
