# Relay beta support

Contact `support@relayforcodex.com` for beta setup, pairing, accessibility,
revocation, Emergency Stop, or account deletion. The mailbox and response
process must be operational before the beta is submitted.

Never send credentials, magic links, pairing codes, prompts, commands,
repository paths, task output, or audio in a support request. Export only the
redacted diagnostic package from Relay for Mac.

For connection problems, keep the Mac awake, confirm Relay Cloud is connected,
and refresh the watch. An offline watch remains read-only by design. For a lost
watch, revoke it from Relay for Mac. For suspected compromise, use Emergency
Stop before contacting support.

Report vulnerabilities through GitHub private vulnerability reporting when it
is enabled. Do not disclose a vulnerability in a public issue before the owner
has a private opportunity to investigate it.

Delete an account from **Relay for Mac > Relay Cloud > Delete Relay Account**.
If the Mac is unavailable, email support from the invited address. Never send a
refresh token or device credential. Deletion does not remove local Codex tasks
or repositories.
