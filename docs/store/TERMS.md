# Relay terms draft

The owner and legal reviewer must supply the publisher legal entity,
jurisdiction, effective date, support contact, and required warranty and
liability language before distributing an App Store build.

Relay restricts evaluation access to invited users during testing. It does not
host Codex. The user supplies and controls the Apple-silicon Mac, Codex
installation, OpenAI access, Apple Watch, network, repositories, workspaces,
and each approval.

Use Relay with accounts, Macs, Apple Watches, repositories, and workspaces you
have authority to control. Do not bypass pairing, rate limits, revocation, App
Store rules, or security controls.

Test software may disconnect, show stale cached summaries, or contain defects.
Keep source control and independent backups. Review exact commands and
consequences. Use Emergency Stop after device loss or unexpected behavior.
Relay does not queue Apple Watch actions while the Mac is offline.

The owner may withdraw evaluation access to protect users or the service. The
evaluation carries no uptime promise. The project licenses published source
code under Apache License 2.0. Access to the operated service and App Store
build remains separate from that source license.
