# Relay invite-beta terms draft

This is a product-accurate working draft for owner/legal review. The production
terms must identify the final publisher legal entity, jurisdiction, effective
date, support contact, and any legally required warranty/liability language.

Relay is a free, invite-only beta for evaluation. It is not a hosted Codex
service. The user supplies and controls the Mac, Codex installation, OpenAI
access, network, repositories, workspaces, and each approval.

Use Relay only with accounts, Macs, watches, repositories, and workspaces you
are authorized to control. Do not bypass pairing, rate limits, revocation,
store rules, or security controls.

Beta software may disconnect, display stale cached summaries, or contain
defects. Keep source control and independent backups, review exact commands and
consequences, and use Emergency Stop when a device is lost or behavior is
unexpected. Relay intentionally does not queue watch actions while the Mac is
offline.

Beta access may be withdrawn to protect users or the service. There is no
uptime promise. Source code published by the project is licensed under Apache
License 2.0; access to the operated beta service and store builds is separate
from that source license.
