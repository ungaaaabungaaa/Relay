# Relay MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and ship a native Galaxy Watch6 client plus a localhost-only Mac bridge that can pair securely with the watch and control supported Codex app-server tasks without an emulator.

**Architecture:** A Kotlin/Compose for Wear OS client talks to a TypeScript HTTP/WebSocket bridge on the Mac. The bridge authenticates every request, persists device and audit state in SQLite, and isolates the installed Codex CLI protocol behind a generated, version-aware adapter. The first runnable slice uses LAN development transport; public Funnel ingress stays disabled until authentication and replay tests pass.

**Tech Stack:** Kotlin 2.x, Jetpack Compose for Wear OS, Android SDK 36, Java 21, Gradle, TypeScript, Node.js 24, Fastify, WebSocket, SQLite, Vitest, Zod, Codex CLI 0.144.5.

## Global Constraints

- Use only the physical Galaxy Watch6; do not install an emulator, AVD, or Wear OS system image.
- Bind the bridge to `127.0.0.1` by default.
- Never put OpenAI, Codex, or bridge private credentials in the APK.
- Do not automate or scrape the Codex desktop UI.
- Route every Codex operation through a version-aware adapter.
- Reject unauthenticated, stale, replayed, or revoked requests before returning task metadata.
- Do not retain raw voice recordings.
- Keep Tailscale Funnel disabled until authentication, replay, revocation, and rate-limit checks pass.
